# ISS-0003 — Resolve external (Slack Connect) user names in message rendering

GitHub: [#3 — Resolve external (Slack Connect) user names in message rendering](https://github.com/digimata/slack/issues/3)

## Problem

Message rendering resolves author names via the workspace directory built from `users.list`. External members from Slack Connect shared channels are not in `users.list`, so they render as raw IDs (e.g. `U0123ABCDEF`) instead of names.

## Fix

When an author ID misses the directory cache, fall back to `users.info` for that ID, cache the result, and render the resolved name. Keep the raw ID on API failure.

Observed in `#shared-channel` (client workspace): the external member renders as `U0123ABCDEF` while workspace members render by name.
