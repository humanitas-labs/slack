# ISS-0004 — Render a placeholder for file/attachment-only messages

GitHub: [#4 — Render a placeholder for file/attachment-only messages](https://github.com/digimata/slack/issues/4)

## Problem

Messages whose content is only a file upload or attachment (no text) render as empty lines in `message list` / `message thread` output — the timestamp and author print with nothing after them, which reads like a bug.

## Fix

When a message has no text but carries files or attachments, render a placeholder such as `[file: chart.png]` (one per file, with name) or `[attachment]` when nothing better is available.

Observed in `#shared-channel` (client workspace): two file-only messages render as blank entries.
